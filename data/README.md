# Data

Place `Telehome_Analytics_Synthetic_Dataset.xlsx` in this folder.

The workbook is **fully synthetic** (no real patients, staff or company data) and contains four sheets:
`Referrals` (1,500 rows), `Staff` (20 rows), `ServiceTypes` (5 rows) and `DataDictionary`.
Some data-quality issues were deliberately included (missing values, inconsistent casing, stray whitespace)
and are cleaned in Power Query.
